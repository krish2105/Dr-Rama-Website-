# Social media templates

Decorative blue-pottery artwork for Instagram, Facebook and WhatsApp. No people, no clinic scenes, no text.
Add all words yourself in Canva (English and Hindi), because AI image tools misspell text.

- `templates/` has each template at its posting size (1:1, 4:5, 9:16, 16:9). Slide files `12_First_Visit_Slide_1..4` are cut from the four-panel sheet and are slightly soft; regenerate them at full size if you want them sharper.
- Fonts to match the website: Newsreader (headings), DM Sans (body), Mukta (Hindi). Colours: ivory #F6F1E4, cobalt #1D4E9F, navy #13203F, brass #B58A33.
- Never place an AI image of the clinic, certificates or the entrance in a post. If you post the AI-enhanced room image, write "Image enhanced with AI from a real photograph."
- The full plan, captions and ad copy are in `docs/Rajesh-Homeo-Home-Instagram-Meta-Ads-Launch-Pack.docx`.
